Профиль ученика

GET /student/{id}, PATCH nickname/avatar. Изменения сохраняются через API.



Детали текущей группы
GET /group/id/{group_id}. Список участников указан слева.
Занятие завершено
POST /group/id/{group_id}/practice-completed. Начисляет награду всем ученикам выбранной группы.
Управление учениками группы
Добавление: PUT /group/id/{group_id}/student. Удаление: DELETE /group/id/{group_id}/student/{student_id}.
Для удаления выберите ученика из списка активной группы.
