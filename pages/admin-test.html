Проверка админских действий

Войдите с паролем из ADMIN_PASSWORD. Здесь можно проверить создание учителей, курсов, групп и наград, а также назначение учителей.

Вход администратора

Пароль не сохраняется в браузере. При пустом ADMIN_PASSWORD используйте пароль, выведенный сервером при запуске.

Регистрация учителя

Код доступа показывается после создания — передайте его учителю.

Создание курса

Курс появится в открытом списке курсов.

Создание группы

Можно сразу назначить до двух учителей.

Для выбора нескольких пунктов используйте Ctrl (Windows) или Cmd (Mac).

Назначение учителей

Сохранение заменяет текущий список назначений.

Оставьте пустым, чтобы снять назначения.

Создание награды

Для привилегии категория курса не указывается.

Обновление списков

Проверка доступности курсов, групп и учителей.

Проверка профиля ученика
